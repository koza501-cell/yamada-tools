## 1. なぜ家計簿アプリは続かず、ChatGPT家計簿は続くのか

「家計簿アプリをダウンロードして1週間で挫折」「ノートに書き始めたけどレシートが溜まる」——これは**家計管理の最も普遍的な失敗パターン**です。家計簿アプリの継続率は、業界標準で **3ヶ月後に約20%、6ヶ月後に約10%**といわれています。

続かない理由は明確で、次の3つに集約されます。

1. **入力作業が単調**：金額を毎日打ち込む行為そのものに価値を感じられない
2. **分析が浅い**：「先月より食費が増えた」程度の気づきしか得られない
3. **アクションに繋がらない**：データを見ても何を変えればいいか分からない

ChatGPTを使った家計管理が続く理由は、**この3つすべてを逆転させる**点にあります。

- **対話形式で記録**：「今日スーパーで3,200円使った」と話しかけるだけ
- **AIが分析を実施**：支出パターン・異常値・改善余地を自動で抽出
- **具体的なアクションを提案**：「動画配信サブスクを2つ解約すれば月2,400円削減」のように行動レベルで提案

本記事では、この3つの逆転を **4週間で習慣化**する方法を解説します。

## 2. 準備するもの — 無料でできる構成（5分で完了）

ChatGPTで家計簿を始めるのに必要なのは、次の3点だけです。

### 2.1 必要なもの

| 項目 | 必須/任意 | 費用 |
|---|---|---|
| ChatGPT アカウント（無料プランでOK） | 必須 | 0円 |
| スプレッドシート（Excel または Google Sheets） | 必須 | 0円〜 |
| スマホのカメラ（レシート撮影用） | 任意 | 0円 |
| ChatGPT Plus | 任意（画像アップロード機能を使う場合） | 月額3,300円 |

**無料プランで完結**します。GPT-4oが無料プランでも利用可能なため、月100件程度の家計入力なら有料プランは不要です。

### 2.2 ChatGPTのプライバシー設定（必ず実施）

家計データは個人情報を含みます。必ず次の設定をしてください。

1. ChatGPT を開く
2. Settings > Data controls
3. **「Improve the model for everyone」を OFF**

これにより、入力した家計データがOpenAIの学習データに使われることを防げます。詳細は[セクション8](#h2-8)で解説します。

### 2.3 スプレッドシートのテンプレート

ChatGPTに渡すデータ形式は、次のような単純なCSV風テキストで十分です。

```
日付 | 項目 | カテゴリ | 金額 | メモ
3/1 | 食費 | スーパー | 8,200 | まとめ買い
3/2 | サブスク | 動画配信 | 1,200 | Netflix
3/3 | 外食 | ランチ | 1,500 | 友人と
3/5 | 食費 | スーパー | 4,800 | 週末買い物
3/6 | 娯楽 | 映画 | 3,000 | 家族で
```

カテゴリ名は途中で変えても問題ありません（ChatGPTが整理してくれます）。

## 3. Week 1：データ準備 — レシートをCSVテキストに変換する

最初の1週間で、データを **「ChatGPTが分析しやすい形」** に整える習慣を作ります。

### 3.1 月曜〜金曜：レシートを毎日CSVに転記

帰宅後 **5分以内**で、その日のレシートをスプレッドシートに転記します。完璧を目指さないことが重要です。

**転記のコツ：**
- 細かい品目は無視し、**店名・カテゴリ・金額のみ**入力
- 不明なカテゴリは「その他」で構いません（Week 2でAIが再分類）
- 電子マネー・クレジットカードの利用も同じ日に記入

### 3.2 土曜：1週間分のデータをChatGPTに渡す

土曜の朝、スプレッドシートをコピーしてChatGPTに貼り付け、次のプロンプトを実行します。

```
あなたは家計管理の専門家（FP）です。
以下の1週間分の支出データを次の観点で整理してください。

【1週間分の支出データ】
（スプレッドシートをコピペ）

【整理してほしい内容】
1. カテゴリ別の合計（食費、外食、娯楽、サブスク、交通、その他）
2. 1週間の合計金額
3. 最も金額が大きかった項目トップ3
4. 「衝動的・意外に多い」と感じられる支出があれば指摘
5. 来週試せる節約アイデアを3つ（必ず数値で削減見込みを提示）

出力はMarkdown表形式でお願いします。
```

ここで得られる気づきが、家計改善の出発点になります。

### 3.3 日曜：週次サマリーをノートに残す（任意）

スプレッドシートの末尾、または別シートに「気づきメモ」として週1行だけ残します。例：

```
Week 1: 外食が¥6,500（予算¥4,000を超過）。来週は週1回に減らす。
```

これを4週続けると、自然に **「自分の支出のクセ」**が見えてきます。

## 4. Week 2：支出分類 — 必要支出と裁量支出に振り分ける

Week 1でデータの取り方が習慣化したら、Week 2は分類の精度を上げます。FP（ファイナンシャルプランナー）が使う **「必要支出」と「裁量支出」**の二分法を導入します。

### 4.1 必要支出と裁量支出の違い

| 区分 | 定義 | 例 |
|---|---|---|
| **必要支出** | 生活に必須、削減困難 | 家賃、食費（自炊分）、光熱費、保険料、通信費の基本部分 |
| **裁量支出** | 見直し可能、嗜好性が高い | 外食、サブスク、娯楽、衝動買い、嗜好品 |

**家計改善の対象は裁量支出**です。必要支出を無理に削ると生活の質が落ち、リバウンドします。

### 4.2 Week 2のメインプロンプト

```
あなたは家計管理の専門家です。以下の家計データを
「必要支出」と「裁量支出」に分類し、削減可能な支出を
特定してください。

【1ヶ月分の支出データ】
（スプレッドシートを貼り付け）

【家族構成】
（例：夫婦＋小学生の子供2人）

【出力フォーマット】
■ 必要支出
- カテゴリ名：金額（合計に対する割合）
- 削減可能性のコメント

■ 裁量支出
- カテゴリ名：金額（合計に対する割合）
- 削減可能性のコメント
- 推奨される削減アクション（具体策）

■ 月間サマリー
- 必要支出合計
- 裁量支出合計
- 削減ポテンシャル（裁量支出のうち見直し可能な金額の合計）
```

### 4.3 分類結果の活用 — 「家計の体質」が見える

実際の家計でこのプロンプトを実行すると、典型的には次のような結果が出ます。

**実例（4人家族、月収50万円）：**
- 必要支出合計：32万円（64%）
- 裁量支出合計：18万円（36%）
- 削減ポテンシャル：5万円（裁量支出の約28%）

裁量支出が30%を超えていれば改善余地は十分です。次のWeek 3で、その削減を実行します。

<a id="h2-5"></a>
## 5. Week 3：節約案の生成 — 月3万円削減の実例とプロンプト

ここまでで「どこを削るか」が見えています。Week 3では、ChatGPTに**具体的な削減プランを生成させる**フェーズに入ります。

### 5.1 実例：4人家族の月29,500円削減ケース

**Before（Week 2の分析結果）：**

```
裁量支出 内訳：
- 外食：48,000円
- サブスク：6,500円（動画配信×3、音楽×1、ニュース×1）
- 娯楽（映画・趣味）：22,000円
- 衝動買い（コンビニ・100円ショップ）：18,000円
- 嗜好品（カフェ・お菓子）：15,000円
合計：109,500円
```

**ChatGPTに渡したプロンプト：**

```
上記の裁量支出を分析し、次の制約のもとで具体的な
節約プランを作ってください。

【制約】
1. 月3万円の削減を目標とする
2. 家族の幸福度を大きく下げない（外食ゼロ、娯楽ゼロは禁止）
3. 4週間で実行可能な具体的なアクション
4. 各アクションに「期待される月次削減額」を必ず付ける
5. ハルシネーションを避け、数値の根拠を明示

【出力】
- アクション名
- 月次削減額（円）
- 実行難易度（低・中・高）
- 失敗しやすいポイントとその対策
```

**ChatGPTの回答（実例）：**

```
■ アクション1：動画配信サブスクを2つ解約
- 月次削減額：2,400円
- 難易度：低
- 失敗しやすいポイント：家族の反対 → 解約前に家族で
  「直近2ヶ月で誰がどのサービスを何回使ったか」を確認

■ アクション2：外食を週2回→週1回に変更（自炊増）
- 月次削減額：18,000円
- 難易度：中
- 失敗しやすいポイント：疲れた日の自炊負担 →
  作り置き or 弁当宅配サービスで補完

■ アクション3：コンビニ利用を「週1回まで」のルール化
- 月次削減額：6,000円
- 難易度：中
- 失敗しやすいポイント：習慣の壁 →
  スーパーでの「コンビニ風おやつ」買い置きで代替

■ アクション4：カフェを月8回→月4回に減らす
- 月次削減額：3,200円
- 難易度：低
- 失敗しやすいポイント：気分転換不足 →
  自宅でドリップコーヒー導入

合計月次削減見込み：29,500円
```

### 5.2 削減プランの実行のコツ

- **全部一度に始めない** — アクション1と4（低難易度）から開始
- **2週間で慣れたら**、アクション2と3を追加
- **削減した金額の使い道を決めておく** — [iDeCo/NISA計算](https://yamada-tools.jp/finance/ideco-nisa-calculator)で長期試算
- **家族とプランを共有** — 1人で進めると挫折しやすい

### 5.3 「節約だけ」ではなく「収入見直し」も同時にやる

支出削減と並行して、収入面の最適化も検討してください。

- 住宅ローンの借り換え：[住宅ローンシミュレーション2026](https://yamada-tools.jp/blog/jutaku-loan-simulation-2026)
- iDeCo/NISA枠の活用：[iDeCo/NISA計算ツール](https://yamada-tools.jp/finance/ideco-nisa-calculator)
- 副業所得の見直し：[副業確定申告チェッカー](https://yamada-tools.jp/finance/fukugyou-shinkoku-checker)
- 配偶者控除の最適化：[配偶者控除計算](https://yamada-tools.jp/finance/haigusha-kojo-calculator)

**節約と収入見直しは、両輪で進めると効果が2〜3倍**になります。

## 6. Week 4：月次レビューの自動化 — 来月から再現する仕組み

Week 1〜3で得た学びを、毎月再現するための**運用テンプレート**を作ります。

### 6.1 月末の30分ルーティン（毎月末の土曜推奨）

**ステップ1（5分）**：スプレッドシートを1ヶ月分まとめて整理

**ステップ2（10分）**：次のプロンプトを実行

```
あなたは家計管理の専門家です。以下は今月の家計データです。
先月との比較で、家計の傾向と異常値を抽出してください。

【今月のデータ】
（スプレッドシートを貼り付け）

【先月のサマリー】
- 必要支出：（先月の金額）
- 裁量支出：（先月の金額）
- 主要削減目標：（先月設定したもの）

【出力】
1. 今月の必要支出と裁量支出の合計、先月比
2. カテゴリ別の前月比（+10%以上、-10%以下のものに ⚠️ フラグ）
3. 削減目標の達成度（達成・未達・部分達成）
4. 来月に向けたアクション3つ
5. 注意すべき支出パターン（傾向的に増えているもの）
```

**ステップ3（5分）**：結果をノートに記録（家族で共有）

**ステップ4（10分）**：年間の累計を確認

「月29,500円削減 × 12ヶ月 = **年間354,000円**」を確認すると、続けるモチベーションが維持できます。

### 6.2 自動化を進めるなら：NotebookLMやGPTsの活用

毎月同じプロンプトを使うなら、次の選択肢があります。

- **NotebookLM**（Google提供、無料）：データをアップロードして対話形式で分析できる
- **ChatGPTのGPTs**（Plus契約者向け）：カスタムGPTで毎月の家計用専用AIを作成
- **マネーフォワード ME**：銀行・カード連携で自動取得（一部有料）

ただし、**自動化を急ぐとプライバシーリスクが上がります**。手動運用のメリットは「何が記録されているか自分で把握できる」点です。

## 8. ChatGPT家計簿の注意点 — 情報漏洩とハルシネーション対策

ChatGPTを家計管理に使う際の **最大のリスク2つ**と対策を解説します。

### 8.1 情報漏洩リスク

**家計データには個人情報が含まれます。** 銀行名、口座番号、クレジットカード番号、配偶者・子供の名前、住所、勤務先などをChatGPTに渡すと、漏洩リスクが発生します。

**対策：**

1. **学習用データ利用をOFF**：Settings > Data controls > Improve the model for everyone を OFF
2. **個人特定情報をマスキング**：「夫の年収」「妻の年収」のように匿名化、口座番号やクレカ番号は絶対に入力しない
3. **店名・サービス名は省略**：「ABCスーパー」ではなく「スーパー」と記載
4. **ChatGPTのチャット履歴を定期削除**：月1回、過去の家計チャットを削除

### 8.2 ハルシネーションリスク

ChatGPTは「もっともらしい嘘」を生成します。**家計改善で最も危険なのは、税制度や控除額に関する誤情報**です。

**よくあるハルシネーションの例：**
- 「ふるさと納税の上限額は◯円」と具体的な金額を提示するが、実際は世帯収入で大きく変わる
- 「医療費控除の対象になります」と断言するが、実際は対象外
- 「iDeCoの掛金上限は月23,000円」と古い数値を提示

**対策：**

- 税額・控除額は必ず[yamada-toolsの所得税シミュレーション](https://yamada-tools.jp/blog/shotokuzei-keisan-simulation-2026)で再計算
- ふるさと納税は[総務省公式シミュレーター](https://www.soumu.go.jp/main_sosiki/jichi_zeisei/czaisei/czaisei_seido/furusato/mechanism/deduction.html)で確認
- 医療費控除は[医療費控除計算](https://yamada-tools.jp/finance/iryouhi-koujo-calculator)で確認

## よくある質問（FAQ）

**Q1. ChatGPT無料プランで家計簿は十分に管理できますか？**
はい、十分です。GPT-4oが無料プランでも利用可能で、月100件程度の家計入力なら有料プランは不要です。画像（レシート写真）を直接アップロードしたい場合のみPlus（月額3,300円）が便利ですが、テキスト転記で代替できます。

**Q2. 家計データをChatGPTに渡しても安全ですか？**
ChatGPTの設定で「Improve the model for everyone」をOFFにし、銀行口座番号・クレジットカード番号などの特定情報をマスキングすれば、リスクは大きく下げられます。詳細は[セクション8.1](#h2-8)を参照してください。

**Q3. どれくらいの期間で節約効果が出ますか？**
本記事の4週間プランに沿えば、**1ヶ月目から月1〜3万円の削減**が見込めます。月29,500円の削減実例（4人家族）は[セクション5.1](#h2-5)で公開しています。家族構成や現状の支出により幅があります。

**Q4. ふるさと納税の上限額をChatGPTに聞いて大丈夫ですか？**
**目安は聞いても、最終判断は使わないでください**。控除上限は年収、家族構成、住宅ローン控除、iDeCoの有無で大きく変わるため、ChatGPTのハルシネーションが起こりやすい領域です。[総務省公式シミュレーター](https://www.soumu.go.jp/main_sosiki/jichi_zeisei/czaisei/czaisei_seido/furusato/mechanism/deduction.html)で必ず確認してください。

**Q5. サブスクの解約は本当に節約効果がありますか？**
あります。サブスクは「使っていないのに気づかない」最も典型的なリーク（漏れ）です。[セクション7.9のサブスク棚卸しプロンプト](#h2-7)で2ヶ月の利用頻度を確認すると、家庭の20〜40%は2つ以上の不要サブスクを抱えていることが分かります。

**Q6. 家族にChatGPT家計簿を共有するコツは？**
**「節約のため」ではなく「ゴールのため」**に枠組みを変えるのがコツです。「外食を減らす」→「年35万円の海外旅行資金を作る」、「サブスクを解約」→「子供の習い事1つ追加」のように、節約した金額の使い道を先に決めると家族の協力が得られます。

**Q7. ChatGPTの代わりにGemini や Claude でも家計簿管理できますか？**
できます。本記事のプロンプトは Gemini、Claude、Perplexity でもほぼそのまま使用可能です。日本語の精度は ChatGPT GPT-4o と Gemini が現状ではトップで、Claude は分析の深さに強みがあります。

**Q8. NotebookLM と ChatGPT の使い分けは？**
ChatGPTは**対話・修正の柔軟性**、NotebookLMは**ファイルを丸ごとアップロードして分析**するのが得意です。日常の記録はChatGPT、月次の深掘り分析はNotebookLMという使い分けが効果的です。
